# assay-anchors

[Assay](https://github.com/) 不可修改日誌的錨點紀錄。**這個 repo 是公開的。**

每一行是某個時間點日誌鏈頭的雜湊：

| 欄位 | 意義 |
|------|------|
| `anchored_at` | 錨定當下的 UTC 時間 |
| `date` | 錨定日期 |
| `seq` | 當時日誌的最後一筆序號 |
| `n_entries` | 當時日誌的總筆數 |
| `head_hash` | 當時鏈頭的 SHA-256 |

**這裡沒有任何一筆紀錄的內容。** 沒有標的、沒有部位、沒有預測、沒有理由。
雜湊是單向的，反推不出原始內容。

## 這個 repo 的用途

日誌本身放在私人的程式碼 repo，本機的雜湊鏈只能證明「鏈內部自洽」——
有檔案權限的人可以把整條鏈重算一遍，重算後一樣自洽。

把鏈頭雜湊推到這裡，重算過的鏈就會跟已經公開的歷史對不上。
**前提是這個 repo 要開分支保護、禁止強制推送**，否則歷史一樣能被改寫。

## 不要手動編輯

這個檔案只能由 `python -m assay.journal.cli anchor --push` 附加。
手動改任何一行，都會讓之前所有的錨定失去意義。
